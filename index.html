Mission: The CEO just clicked a phishing link, and malware is spreading through the company building. The IT team is locked out of the control room.

🔥 The Gatehouse

Topic: Firewalls

The guard desk shows the firewall rules. The malware got in because one rule accidentally allows dangerous traffic. Which rule is the problem?

Rule 1: ALLOW  Any → Web Server        port 443 (HTTPS)
Rule 2: ALLOW  Any → Mail Server       port 25  (Email)
Rule 3: DENY   Internet → Internal LAN all ports
Rule 4: ALLOW  Any → Any                all ports
Rule 5: ALLOW  Admin PC → Router       port 22  (SSH)
A good firewall follows “deny by default.” Look for the rule that lets every source reach every destination on every port.

📶 The Wi-Fi Lounge

Topic: Wi-Fi security

The attacker slipped in through the lounge router. Check its settings and select all 3 insecure settings.

WEP is old and easy to crack, WPS can be brute-forced, and default passwords are known to every attacker. The other two settings are good.

🔑 The HR Office

Topic: Management controls and policies

The phishing email worked because of weak security habits. Select all 3 risky practices from the employee handbook.

Good policies include MFA and auto-lock. The risky ones are exposed passwords, shared accounts, and no training or password reuse.
